# cmsb_PayPvp
## 概要
ワールド生成時に導入し、2人3チームでPVPをするといったデータパックです。

## ルール
### 1. 準備フェーズ <small>(おすすめ時間:30分以上)</small>
いつものMinecraftのように物資を集め、戦いに備えて装備を強化するフェーズです。<br>
ただし、このフェーズでは「タスク」をクリアすることで独自の通貨「すばペイ」を獲得できます。<br>
このすばペイは、戦闘をより有利にするためのアイテムの購入に必要です。

### 2. 購入フェーズ <small>(おすすめ時間:3分)</small>
準備フェーズで集めたすばペイを使用してアイテムを購入するフェーズです。<br>
様々なユニークアイテムが存在します。

### 3. 戦闘フェーズ <small>(推定時間:約10分)</small>
伸縮するワールドボーダーの中でチームと協力し、他チームを攻撃するフェーズです。<br>
残機制で、1回のみ復活可能(インベントリ保持)です。

## このデータパックの使い方
ワールドに導入後、`/function _settings:`を実行することで設定を開くことが可能です。<br>
角括弧で囲われた文字をクリックすることでホバーテキスト通りの指示を実行できます。
